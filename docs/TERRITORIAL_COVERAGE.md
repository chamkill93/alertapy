# Cobertura territorial

El panel administrativo muestra un **Índice de capacidad de monitoreo** por departamento. Combina:

- conectores oficiales con evidencia;
- prensa nacional y regional;
- sensores;
- infraestructura territorial disponible;
- recencia de actualización.

Cada componente se limita a 100 y el resultado ponderado se usa únicamente para detectar brechas operativas.

> El índice no representa el porcentaje de todos los acontecimientos reales detectados. Tampoco mide veracidad editorial ni garantiza que no existan hechos sin publicar.

La población censal de un distrito es contexto. Solo se presenta `population_potential` cuando existe una geometría o cifra respaldada por un método explícito; nunca se etiqueta automáticamente como personas afectadas.
