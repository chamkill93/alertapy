# AlertaPY UI/UX RC1

Sistema visual integrado sobre la aplicación existente, sin dependencias de UI ni un segundo motor de marcadores.

- `css/alertapy-ui-kit.css`: tokens, botones, toggles, controles segmentados, foco y controles Leaflet.
- `icons/monitoring/`: SVG oficiales del paquete DMH entregado.
- Los iconos generales y de incidentes permanecen centralizados en `public/js/alertapy-icons.js`, porque el ZIP recibido referencia esos SVG pero no los incluye. Este archivo es la única fuente de glifos usada por filtros, marcadores, tarjetas y controles.

El logo y los recursos de marca se conservan en `public/images/`.
